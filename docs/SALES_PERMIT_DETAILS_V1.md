# Sales-friendly permit detail V1 — North Carolina

**November 12, 2026**

## What changed

Salespeople should land on a readable project page, **not a raw ArcGIS service endpoint**.

The construction-opportunities table now has:
- **Permit details:** the permit number links to the project's own `permit.html?id=<source:permit-number>` page, generated by GitHub Pages.
- **Official source:** the original GIS feature query when the ArcGIS OBJECTID is available, otherwise the government's original data layer URL. Greensboro also offers a separate direct link to the city's official individual-permit page.

The dedicated **`public/permit.html`** is a static, responsive sales view. It loads the current `public/data/permits.json`, resolves a record by its exact source-scoped `id`, and presents the project without calling a third-party contact finder or inventing missing fields.

Sections:
1. Site/project name, source jurisdiction, issuance status and classification.
2. Estimated project value, permit number and original issue date.
3. Construction scope, work type, units, stories, square footage when published.
4. Business/contractor name with direct phone and email actions when the source lists them.
5. Official individual city permit (where supported), exact government GIS source feature (OBJECTID) and original ArcGIS layer link, clearly separated.
6. Map/address lookup and a copyable project summary with a reminder that the record is only screened, not independently verified.

## Enrichment source fields

Raleigh's **Building Permits Issued Past 180 Days** ArcGIS feature layer advertises the following official attributes, which are now extracted from each collected feature when present:

| Display | Raleigh official field |
|---|---|
| Project name | `projectname` |
| Builder / GC | `contractorcompanyname` |
| Business phone | `contractorphone` |
| Business email | `contractoremail` |
| Contractor license | `contractorlicnum` |
| Doing business as | `contractordba` |
| Contractor mailing address | `contractoraddress1`, `contractorcity`, `contractorstate`, `contractorzip` |
| Total square footage | `totalsqft` |
| Stories | `numberstories` |
| Units | `housingunitstotal` |
| Work class | Source-specific work fields |
| Permit type | Source-specific permit-type fields |

Official field metadata:
https://services.arcgis.com/v400IkDOw1ad7Yad/arcgis/rest/services/Building_Permits_Issued_Past_180_Days/FeatureServer/0?f=pjson

Other active jurisdictions (New Hanover, Mecklenburg, Greensboro) use their existing approved source fields for builder name, classification, description, valuation and address. The details page is shared across markets, but **contact fields not confirmed in a jurisdiction's selected GIS feed remain empty**. Mecklenburg's current selected layer does not expose a builder, so the page explicitly says it is not listed.

`src/collect.py` now preserves `source_record_url`, a query by the ArcGIS feature's unique `OBJECTID` when available, separate from:
- `source_url`: official GIS layer (provenance)
- `permit_detail_url`: official individual-permit website only for a known, supported pattern (currently Greensboro)
- Our own sales page: `permit.html?id=...`

The dashboard CSV includes `sales_detail_url`, `source_record_url`, business phone/email/license, official permit-detail URL and the raw source URL. Generated links to the sales details are same-origin and contain the source-scoped permit ID.

## Data integrity and security

- All external links are HTTPS and constrained to known government GIS/permit hostnames.
- All dynamic permit content is written into the page as text nodes/textContent; no HTML from a government description is interpreted as markup.
- Phone and email click targets validate the public contact field shape before creating `tel:` or `mailto:` links.
- Missing fields appear as **Not provided** rather than guessed or scraped from other businesses.
- Amounts and quantities are formatted without inventing nonzero values.
- Empty/invalid/GIS-scope-only record IDs cannot produce misleading exact record links.
- The detail page preserves the current `screened government record — not independently verified` classification and requires checking the issuing agency for current status.
